# หอกพิฆาตเงาจันทร์ — Draft v0.1

> **ยังไม่ใช่ Canon:** ผู้เขียนเลือกแนวไพ่ตายเป็นวิชาขว้างหอกสำหรับพระเอกสำนักเงาจันทร์ แต่ชื่อ กลไกและพัฒนาการในไฟล์นี้ยังเป็นข้อเสนอรออนุมัติ

## Core concept
- เวท ยันต์ มายา ค่ายกล และวิชาตัวเบาเป็นเครื่องมือหลอกล่อ/เตรียมโอกาส
- ไพ่ตายจริงคือ **วิชาขว้างหอกทางกายภาพที่ฝึกซ้ำอย่างหนัก** มีการเสริมพลังตามระดับยุทธ์
- ไม่ใช่การเสกหอกและไม่ใช่เวทที่โจมตีแทนผู้ขว้าง
- จุดเด่นอยู่ที่จังหวะปล่อย ความแม่นยำ การถ่ายแรง และความประหลาดใจของศัตรู
- แนวคิด: **หนึ่งหอก หนึ่งโอกาส**

## Suggested four volumes
1. จอมยุทธ์ C–A: **หอกหนึ่งลมหายใจ** — รากฐานกายภาพ สมดุล และความแม่นยำ
2. ยอดยุทธ์ C–A: **หอกทะลวงเงา** — ถ่ายทอดปราณเข้าสู่หอก
3. ปรมาจารย์ C–A: **หอกไร้เสียง** — ประสานเจตจำนงยุทธ์และลดสัญญาณก่อนโจมตี
4. จักรพรรดิ C–A: **หอกจันทร์ดับ** — รวบรวมกำลังและพลังขั้นสูงไว้ในการโจมตีหนึ่งครั้ง

**หมายเหตุ:** ระดับพลังตัวละครและระดับความเชี่ยวชาญวิชาเป็นคนละข้อมูลกัน การถึงขั้นหนึ่งไม่ได้แปลว่าชำนาญเทคนิคนั้นทันที

## Typical combat sequence
1. ประเมินคู่ต่อสู้และเตรียมทางหนี
2. ใช้เวท/ยันต์/มายาล่อความสนใจ
3. หาโอกาสและตำแหน่งสำหรับขว้าง
4. ใช้หอกโจมตีครั้งเดียวที่เตรียมไว้
5. ถอยหรือเปลี่ยนแผนหากไม่สำเร็จ

## Proposed limitations
- ต้องอาศัยจังหวะและระยะเหมาะสม ถูกประชิดอย่างต่อเนื่องแล้วใช้ลำบาก
- ขว้างแล้วเสียอาวุธจนกว่าจะเก็บคืนหรือมีสำรอง
- บาดเจ็บของกล้ามเนื้อ ข้อต่อ และลำตัวกระทบการใช้
- ท่าหลักใช้ลมปราณสูง และการล้มเหลวมีต้นทุนมาก
- ศัตรูยังหลบ ปัด ป้องกัน หรือใช้สิ่งกีดขวางได้
- เมื่อไพ่ตายถูกเปิดเผย ยากที่จะสร้างความประหลาดใจซ้ำ
- **ไม่สามารถข้ามช่องว่างช่วงพลังใหญ่โดยอัตโนมัติ** ตาม Canon ระบบพลัง

## Open decisions
- ยืนยันหรือเปลี่ยนชื่อวิชาและชื่อสี่ภาค
- หอกเป็นอาวุธธรรมดา หอกพิเศษ หรือสามารถใช้หลายชนิด
- รูปแบบการพก/ซ่อนหอก
- ความถี่และต้นทุนของท่าสุดยอด
- วิธีฝึกที่พระเอกได้รับและเหตุผลที่ปิดบังฝีมือ
